Fetching your reports from Three Rings…

    This usually takes a few seconds. Keep the Three Rings tab open until the dashboard appears.

    Rota wrapped

    Builds the director group dashboard from two files saved from Three Rings. Everything happens inside this browser window.

    Nothing is uploaded or sent anywhere. Close the tab and the data is gone.

    1. Shifts

    Log in to Three Rings first, then click this link. It opens a page of text. Save it with Ctrl+S (on a Mac, Cmd+S).

    Closed shifts report (recommended). Export the closed shifts report from Three Rings for the same dates and drop it here. Without it, a shift counts as closed when it has fewer than two people on it.

    2. Volunteers

    Click this link. It downloads the Directory as a spreadsheet file (.csv).

    https://www.3r.org.uk/directory.csv

    If your branch exports the Directory another way, any CSV with one row per volunteer works.

    Roles report (recommended). Export the Roles report from Stats in Three Rings as a .csv and drop it here. It decides who is a listening volunteer, probationer or shift leader, and matches people to the rota by their Three Rings ID. You can use it on its own, without the Directory file, but then start dates and the overnight exemption have to be added in the list.

    3. Leave of absence

    Export the volunteer activity report from Stats in Three Rings as a .csv and drop it here. Then check the drop-downs below have found the volunteer's name and the leave start and end dates.

    4. Check the list

    Untick anyone who isn't a listening volunteer or probationer, and check the Leader ticks match who leads. Tick anyone exempt from overnights, and add dates for anyone on leave of absence (leave "Back" empty if there is no return date). If someone's name doesn't match how it appears on the rota, edit it here.
